# Contributing

This repo tracks one person's actual, live home server — not a general-purpose
project accepting outside changes. See the Disclaimer in `README.md` for what
that means in practice.

## Issues

Welcome. If something in a manifest is wrong, a doc is stale or contradicts
what's actually deployed, or a piece of the setup doesn't make sense from the
outside, open an issue.

Keep them succinct: what you found, where (file/path), and why it looks
wrong. No template, no need to propose a fix.

## Pull requests

Will almost certainly be rejected, regardless of quality. Every manifest here
tracks a real cluster this repo's owner runs personally — merging someone
else's change means either applying it to that live infrastructure sight
unseen or letting the repo drift from what's actually deployed, and neither
is acceptable. If you've found something worth fixing, open an issue instead
and describe it; if it's a real gap, it'll get fixed by the owner.
